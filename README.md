📊 Netflix Movies Data Analysis using Python

This project performs an end-to-end Exploratory Data Analysis (EDA) on a Netflix movie dataset to uncover valuable insights into movie trends, genres, popularity, ratings, and release years. The analysis includes data cleaning, preprocessing, feature engineering, and interactive visualizations to transform raw data into meaningful business insights.

🚀 Key Features
✅ Data Cleaning & Preprocessing
✅ Duplicate and Missing Value Handling
✅ Date Conversion and Feature Engineering
✅ Genre Transformation using explode()
✅ Exploratory Data Analysis (EDA)
✅ Distribution Analysis of Genres, Ratings & Release Years
✅ Popularity Analysis (Most & Least Popular Movies)
✅ Professional Visualizations using Matplotlib & Seaborn
🛠️ Technologies Used
Python
Pandas
NumPy
Matplotlib
Seaborn
Jupyter Notebook
📈 Insights Generated
Most popular movie genres
Distribution of movie ratings
Movie release trends over the years
Highest and lowest popularity movies
Genre-wise movie frequency analysis
🎯 Project Objective

To demonstrate practical data analysis skills by cleaning, transforming, and visualizing a real-world Netflix dataset while extracting actionable insights that support data-driven decision-making.
